# HTML Tables

A beginner-friendly HTML project demonstrating different types of tables and cell merging techniques using HTML5.

## 🌐 Live Demo

**[View HTML Tables Website](https://abhilashreddy0203-hub.github.io/HTML-Tables/)**

## 📚 Topics Covered

### 1. Student Table
Displays student details, including name, age, course, and college.

### 2. Class Timetable
Demonstrates a weekly class timetable with periods, subjects, and a lunch break.

### 3. Vertical Table
Organizes student information horizontally across columns, including student ID, name, age, and course.

### 4. Merging Columns
Uses the `colspan` attribute to merge table header cells across multiple columns.

### 5. Merging Rows and Columns
Uses the `rowspan` and `colspan` attributes to combine cells and organize student marks for different subjects.
